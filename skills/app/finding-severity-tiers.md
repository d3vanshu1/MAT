## Finding Severity Tier Labels

All module findings use this severity mapping:

| Tier | Label |
|------|-------|
| **Tier 1** | Critical |
| **Tier 2** | Warning |
| **Tier 3** | Info |

Apply consistently across all modules (ERO, CC, SRI, OA, BSS, canonical) when displaying severity in the UI, reports, or summaries.
